FM-1 Firmware Flasher

Install custom firmware on an M-VAVE FM-1 straight from the browser, over USB. Nothing is uploaded anywhere: the page talks to your FM-1 directly.

This browser can't talk to MIDI devices. Flashing works in Chrome, Edge or Opera on a computer, or Chrome on Android with a USB-OTG cable. iPhones and iPads (every iOS browser), Firefox and Safari don't offer Web MIDI. You can still use “Try in browser” below. The page also has to be served over https:// or from localhost, not opened as a file.

1. Connect your FM-1

Plug the FM-1 in with a USB data cable and close any other app that uses MIDI (DAWs, editors, other flasher tabs). The browser will ask to use MIDI devices; allow it, including system-exclusive messages.

2. Pick a firmware

Install a firmware file of your own

For a .fwsc you built yourself. It is checked the same way as the command-line installer: it has to be an FM-1 package, and either carry the Felucca update loader or be M-VAVE's own firmware. The device itself checks it again before writing anything.

If something goes wrong

  • The install was cut off (cable pulled, tab closed): the FM-1 stays in update mode. Reconnect it, press Connect, and press Install on the same firmware again. The write resumes.
  • A new firmware crashes on start: two failed starts in a row bring up SAFE MODE, which this page can still reach. Connect and install any firmware.
  • Back to how it came: install "Back to stock" above. It restores M-VAVE's V15 firmware.
  • No MIDI port appears at all: try another USB cable (it has to carry data) and another port, and close other MIDI apps.

The install protocol and port detection are from fm1-base by Charles Vestal and Leo Kuroshita / Hügelton Instruments (MPL-2.0); see js/fm1ota.js. Not affiliated with M-VAVE. Flashing firmware is at your own risk.
